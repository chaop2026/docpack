## 🔴 공개되는 것은 ``` 블록 **안**뿐이다

세 템플릿(`channel_about_ja.md` · `pinned_comment_ja.md` ·
`upload_default_description_ja.md`)은 전부 같은 규칙을 따른다:

- **``` 블록 안** = 실제로 YouTube 에 붙이는 글. 가드 검사 대상이고, 기계가 읽는 것도 이것이다
- **그 밖** = 주석. 왜 그렇게 썼는지, 무엇을 하지 말라는지. **붙이지 않는다**

규칙이 하나인 이유는 검사 때문이다. 경계가 파일마다 다르면 검사기가 파일마다 달라지고,
검사기가 달라지는 순간 **어떤 파일은 검사되지 않는데 결과는 「위반 0」으로 똑같이 보인다.**
⚠️ 실제로 한 번 겪었다 — 2026-11-16 의 첫 QA 는 파일 전체를 읽어 「금지어 4건」을 냈는데,
그 4건은 전부 **「이 단어를 쓰지 마라」고 적어둔 주석**이었다. 검사가 틀렸던 것이지
글이 틀렸던 것이 아니다. 같은 검사가 **진짜 결함 2건**(필수 문장이 독립 행이 아니었다)도
같이 잡았으므로, 검사를 끄지 않고 **범위를 정확히** 했다.

## 🔴 쇼츠와 긴 영상은 링크 규칙이 **반대**다

| 면 | 링크가 눌리는가 | 그래서 |
|---|---|---|
| 쇼츠 설명란 | **아니다** | URL 을 쓰지 않는다. 쓰면 전환 0인데 증상은 「링크가 있다」뿐이다 |
| 쇼츠 댓글 | **아니다** | 같음 → `pinned_comment_ja.md` 는 **문장으로** 안내한다 |
| 쇼츠 끝 화면 | (링크 아님) | 「プロフィールのリンクから」 — 눌리는 곳으로 **말로** 보낸다 |
| 쇼츠 「관련 동영상」 | 눌린다 | **우리 채널 영상만.** 고급 기능(전화 인증) 필요 |
| **채널 프로필 링크** | **눌린다** | 1번 = 랜딩 |
| **긴 영상** 설명란·댓글 | **눌린다** | 전환의 본진. 첫 2줄 안에 링크 |

이 표가 이 폴더의 존재 이유다. `v2` 초안은 `pinned_comment_ja.md` 에 링크를 넣고
`upload_default_description_ja.md` 를 쇼츠용으로 썼는데, **둘 다 눌리지 않는 면**이었다.
2026-11-16 에 정정했다.

## 계측 — `?via=` 값으로 **어느 면에서 왔는지** 구별된다

| 값 | 어디서 | ep 파라미터 |
|---|---|---|
| `via=youtube` | 채널 프로필 링크 · 쇼츠를 보고 찾아온 경로 | **없다** — 채널 링크는 회차가 아니다 |
| `via=youtube&ep=epNN` | 회차 블로그 링크(쇼츠 설명란에 **적혀** 있지만 눌리지 않으므로, 손으로 친 방문) | 있다 |
| `via=yt_long&ep=epNN` | **긴 영상** 설명란·댓글 | 있다 |

⚠️ `ep` 가 없는 `via=youtube` 는 「회차 불명」이 아니라 **「채널 레벨 유입」** 이다.
두 사실이 다르므로 섞어 읽지 않는다. 주간 표에서는 같은 `youtube` 행에 합쳐지므로,
회차별로 보려면 `ep` 차원을 함께 봐야 한다.
