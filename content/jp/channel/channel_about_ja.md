# チャンネル説明（Studio → カスタマイズ → 基本情報 → 説明）

そのまま貼る。1000字以内。

🔴 **公開されるのは下の ``` ブロックの中だけ**だ。その外は注記で、貼らない。
この境界は好みではなく検査の範囲で、`content/jp/channel/README.md` に書いてある
一つの規則に三つのテンプレートが従っている。

```
提出書類の「黒塗り」を、ブラウザだけで終わらせる方法を紹介しています。

入札の添付書類、本人確認書類、取引先に送る契約書。番号を隠して提出するよう求められる書類は多いのに、その手順はどこにもまとめられていません。付箋を貼って撮影した写しは光で透けることがあり、画像編集アプリで黒い四角を重ねたPDFは文字層が残ることがあります。

このチャンネルでは、書類ごとに「隠すところ」と「残すところ」を分けて、短い動画で説明します。審査に必要な項目まで消してしまうことも差し戻しの原因になるので、両方を扱います。

紹介しているツールは、ファイルをサーバーに送りません。処理はブラウザの中だけで終わります。

発注者や窓口によって、隠す範囲の指定は異なります。
提出先の指示を必ず確認してください。

くわしい手順 → プロフィールのリンク
```

## 使うときの注意

- **1000字以内**（YouTube の上限）。
- 🔴 **URL をここに書かない。** 説明文の URL は環境によってリンクにならず、
  なっても見た目で判断できない。**プロフィールのリンク**（`profile_links.md`）が
  確実に押せる唯一の channel 面だから、そこへ言葉で送る。
- 必須文 `提出先の指示を必ず確認してください。` を**独立した行**で入れている
  （`content/jp/guard_rules.json` の `must_line`）。
- 「絶対」「必ず安全」「防ぎます」は書かない（同ファイルの `forbidden`）。
  法的効果の断定も書かない — 日本の弁護士レビューがまだない。
