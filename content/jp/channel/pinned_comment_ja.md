# ショート動画の固定コメント（毎回、手で貼る）

`{{NN}}` を回次の2桁に、`{{TITLE}}` を記事タイトルに置き換える。

---

```
この回の手順は、ブログ記事にまとめています。
チャンネルの「プロフィールのリンク」から、第{{NN}}回の記事をご覧ください。

隠す範囲は提出先によって違います。
提出先の指示を必ず確認してください。
```

---

## 🔴 ここに URL を書かない

**2026-11-16 の訂正。** v2 の初稿はここに
`https://slimfile.net/ja/blog/...?via=youtube&ep=epNN` を貼っていた。

ショート動画の**説明欄とコメントのリンクは押せない**（2026-11-01 確定事実）。
押せる場所は、チャンネルのプロフィールリンク／長い動画の説明欄・コメント／
ショートの「関連動画」（自チャンネルの動画のみ・高度な機能が必要）だけだ。

⚠️ **これは「効果が薄い」ではなく「0」だ。** そして症状は**「リンクが書いてある」**
だけなので、外から見ると正常と区別がつかない。URL が貼られたコメントは
「導線がある」ように見え、クリックは一度も発生しない。だから文章で送る。

## 長い動画のコメントは別物

長い動画では**押せる**ので、そちらは URL を貼ってよい。
雛形は `upload_default_description_ja.md` にある（`?via=yt_long&ep=epNN`）。

## 貼る前の確認

- [ ] `{{NN}}` `{{TITLE}}` が**置換済み**（`{{` が残っていないか目で見る）
- [ ] URL が**入っていない**
- [ ] 必須文 `提出先の指示を必ず確認してください。` が入っている
- [ ] コメントを**固定**した（貼っただけでは上に出ない）
