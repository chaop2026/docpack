# チャンネル画像の規格（プロフィール写真・バナー・透かし）

**画像ファイルはこのフォルダに置かない。** ブランド素材は `public/safe/brand/` が持ち、
そこは**実際に配信される**ディレクトリだ(OG カード・ファビコン)。同じ絵を2か所に置くと
片方が古くなる。ここに書くのは**規格と、どれを使うか**だけ。

| 面 | 規格 | 使う素材 |
|---|---|---|
| プロフィール写真 | 800×800 PNG、円形に切られる | `public/safe/brand/` のアイコン |
| バナー | 2048×1152、**中央 1235×338 だけが全端末で見える** | 新規（下の文案） |
| 動画の透かし | 150×150 PNG、透過 | プロフィール写真と同じ |

## 🔴 バナーは「中央 1235×338」だけを信じる

テレビでは 2048×1152 全部、PC では 1546×423、スマホでは **1235×338** しか出ない。
読ませたい文字をそれより外に置くと、**作った画面では見えて、見る人の画面では消える**。
`video-thumbnail` のショート表紙の安全領域と同じ理由で、これは好みではなく座標だ。

### バナー中央に入れる文案（2行）

```
提出書類の黒塗りを、ブラウザだけで
入札・本人確認・契約書
```

## 🔴 権限 — 644 でなければ本番で 404 になる

`public/safe/brand/` に画像を追加するときは **644**(ディレクトリは 755)。
Dockerfile は `USER 1000:1000` で動き、`kamal deploy` は**この作業ツリー**から
`COPY . .` する。600 や 700 のままだと、ファビコンも OG カードも**静かに 404** になる。

⚠️ **開発環境では気づかない** — dev は root で動くので見える。
⚠️ **git は実行ビットしか保存しない** — 新しいクローンは正常で、壊れているのは
このディスクだけだ。だから `test/integration/public_assets_readable_test.rb` が
ファイルが world-readable であることを単言している。S8 と S11 で**2回**起きた。

```
# 確認（読み取りのみ）
ls -l public/safe/brand/
```
