## 1. 사실 정리 (정정판)

- 2026-09-25 タイムズカー 부정 접근 탐지·제1보 → 09-28 약 660만 계정 정보 취득 확인(제2보) → 09-29 그중 약 160만 계정에서 본인확인서류 이미지(運転免許証·現住所確認書類·学生証·家族確認書類) 유출 확인(제3보). 共同通信은 住民票の写し도 언급. [제2보](https://share.timescar.jp/news/2026/0928/1815.html) [제3보](https://share.timescar.jp/news/2026/0929/1816.html)
- 집단소송: 변호사 개설 사이트에 10/2 밤까지 1만5천 명 이상 "참가 의사 등록"(共同通信). 원고 수 아님
- 10월 들어 大和証券·物語コーポレーション 등 추가 유출 발표. 경시청에 재교부 상담 쇄도, 福島県 특별 재교부 접수
- 告知要求制限(2020-10-01): 의료보험 사무 외 목적으로 保険者番号·被保険者等記号・番号의 고지를 요구하는 것을 원칙 금지. 예외 있음. QR은 번호 판독 가능 시 동일. 지자체·은행·카드사가 사본 제출 시 마스킹 요청 중. [厚労省](https://www.mhlw.go.jp/stf/newpage_13989.html)

- マイナンバーカード: 一般 身元確認에는 앞면만. 裏面 個人番号 복사·보관은 번호법상 허용 목적(세무·사회보장 등)에 한정. 臓器提供意思表示欄은 앞면 하단

- SNS 이용률(ICT総研 2026-07 보도자료): LINE 71.1 / YouTube 67.6 / X 45.4 / Instagram 42.0 — 연령별 전환율 자료 아님

**핵심 통찰(유지)**: 일본에는 "黒塗り"가 법적 요구+관행으로 존재하고, 개인은 付箋·테이프·편집앱으로 수작업 중. 개인용 무료 웹툴 공백. "透ける黒塗り" 공포에 "래스터 평탄화 + 메타데이터 제거"로 답한다.

## 3. 제품 요구사항 (알파 게이트)

### 3-1 마스킹
- 띠(검정 기본·흰색·지정 1색)만. 별표·부분값 폐지(결정 유지)
- OCR 박스 + 글리프 외곽 여유(2px 고정이 아니라 **박스 높이의 15%**)로 덮고 래스터 평탄화
- 출력 시 **원본 텍스트 레이어·주석·첨부·증분저장·EXIF 전부 제거** 검증
- 지원 외 문서는 자동 마스킹 금지, 수동 사각형+워터마크만

### 3-2 탐지(JP-1) — 정규식 단독 자동마스킹 금지
| 항목 | 방식 | 자동 띠 조건 |
|---|---|---|
| 個人番号 12자리 | NFKC → 숫자 경계 → 레이블(個人番号/マイナンバー) 또는 문서분류 → 체크디지트 함수 | 3조건 충족 시 자동, 아니면 검토 후보 |
| 保険者番号 / 記号・番号・枝番 | 레이블 근접(같은 행·인접 박스) 점수제 | 資格確認書 분류 + 레이블 일치 시 자동 |
| 免許証番号 12자리 | 免許証 분류 + "第"/"番号" 앵커 | 분류 확정 시만 |
| 電話·FAX | NFKC → TEL/電話/携帯/FAX 앵커 + 일본 번호계획 | 앵커 있을 때 자동, 하이픈 없는 값은 후보 |
| 住所 | 郵便番号 → 都道府県 → 市区郡 → 町域 → 丁目番地 → 建物 계층 파서. 漢数字 百·千 포함 | 郵便番호+都道府県 동반 시 자동 |
| 生年月日(和暦) | 和暦·서기 양쪽 | 후보 |
| QR | 이미지 휴리스틱 | 資格確認書 분류 시 자동 |
- **원문↔NFKC 인덱스 매핑 보존**, 이체자(髙/高, 﨑/崎), OCR 혼동(ー/−/―, 〇/0) 단계별 처리, 원본 좌표 역매핑 테스트

### 3-3 프리셋 — 알파 4종만
| 프리셋 | 목적 선택 | 기본 띠 | 해제 가능 |
|---|---|---|---|
| 資格確認書 | 本人確認 | 保険者番号, 記号, 番号, 枝番, QR | 性別(권고) |
| 運転免許証 | 本人確認 | 裏面 備考欄 | 番号 |
| マイナンバーカード | 身元確認 / 個人番号手続 | 身元確認: 裏面 전체 + 앞면 臓器提供欄 | 個人番号手続 선택 시 裏面 해제 |
| 住民票の写し | 用途 선택 | 個人番号, 住民票コード | 本籍, 世帯員 |

### 3-4 워터마크
「{提出先}提出用」「本人確認のみに使用」「転用禁止」+ 날짜. 문구는 "防止"가 아니라 "抑止" 수준으로 안내.

## 4. 더미 데이터 — 비실물 도식형

- **실물 동일 재현 금지**: 종횡비·색·서체·구획을 동시에 복제하지 않음. 카드류는 "필드 위치 도식(와이어프레임형)"으로
- 앞뒤 중앙 대형 「見本・架空・本人確認に使用不可」 영구 표기
- 公安委員会名·市区町村長名·관인·マイナンバー 로고·QR·IC 표시 금지
- 번호는 **체크디지트 불일치** 또는 규격 외 문자(예: 개인번호 12자리 중 'X' 포함)
- 실존 불가 주소(99丁目 등), 架空 인명, 생성 아바타
- 개별 고해상 카드 파일은 공개 배포 금지. 콘텐츠에는 축소 삽화만
- 더미 범위: 알파 4종 × (PDF·JPG 촬영풍·PNG 스캔풍) + 변형(資格確認書 보험자 3종, 住民票 全員/一部·個人番号 유무·외국인) ≈ **20파일**
- 법률 검토 전까지 카드 더미는 내부 테스트 전용
