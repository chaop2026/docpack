세는 단위(채널별 게시물 1건 = 1편, ep 당 최대 3):
- 블로그 = `primary_locale='ja'` 이고 `status='published'`
- X = `package.x.state == 'done'` (JA 스레드 + 영어 답글을 합쳐 1편)
- LinkedIn = `package.posted.linkedin_url` 이 기록돼 있음 (공식 API 미승인이라 수동 게시 → URL 기록이 곧 계측)

`JpWeeklyKpi#p18_counts` 가 세고, 주간 산출(`docs/jp/metrics/YYYY-WW.md`)·승인 화면·검토 메일이

- **2026-10-25 운영 가정 변경**: 채널 X·YouTube·Instagram → **X·YouTube·LinkedIn·블로그**. Instagram 보류(계정 없음·B2B 타깃 불일치·Graph API 요건), 블로그를 허브로 추가. 「보수 예측값에 영향 없음」이라고 단정하지 않는다 — 증거가 없다. 영향은 P18 로 따로 측정한다.
- P3 회신 0 → 문안·대상 교체(전자입찰 대행업체 집중), 가격·제품 유지
