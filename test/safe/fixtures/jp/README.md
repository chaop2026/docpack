# SafeFile JP alpha fixtures — 見本・架空

**These are non-realistic schematic dummies for automated testing. They are not
identity documents, they cannot be used as any, and they must not be
redistributed as standalone images.**

Generated by `gen.py` under the safety conditions of
[strategy v2 §4](../../../../docs/jp/jp_safefile_strategy_v2_2026-10-21.md):

- Never reproduce a real document's aspect ratio, colours, typeface and field
  layout at the same time — card types are drawn as **field-position
  wireframes**, not facsimiles.
- A permanent 「見本・架空・本人確認に使用不可」 overlay across the whole face,
  plus an opaque corner mark that survives downscaling.
- **No** 公安委員会名, **no** 市区町村長名, **no** official seal, **no**
  マイナンバー logo, **no** real QR / 2-D code, **no** IC chip mark.
- Every number either **fails its check digit** (個人番号) or contains a
  character the real format does not allow (免許証番号 ends in `X`).
- Impossible addresses (99丁目), fictitious personal names (架空・見本・仮名・
  試験・例示・模擬), no photographs — the 顔写真欄 is an empty grey panel.

## Status

Strategy v2 §4 holds card-type dummies to **internal test use until a Japanese
lawyer has reviewed them**. They are committed here because the golden harness
(`test/safe/run.mjs`) cannot run without them and `gen.py` is not reproducible
off a Linux box with Noto CJK installed — a regenerated set would shift the box
coordinates every spec file depends on. Treat that as a deliberate, recorded
trade-off, not an approval to publish them anywhere else.

## Layout

```
<document>/<variant>.png          scan-style render (the box table's coordinate frame)
<document>/<variant>.jpg          phone-photo style: rotated ±3°, blurred, darkened
<document>/<variant>.pdf          the PNG placed on a page at half scale
<document>/<variant>.specs.json   box table (PNG pixels) + per-提出目的 expectations
jp_legal_matrix_alpha4.json       the legal matrix these expectations come from
```

`.jpg` box coordinates deliberately do **not** match the table — the rotation is
the point. Golden cases on JPG assert at field level instead; see
`test/safe/README.md`.
